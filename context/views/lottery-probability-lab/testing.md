# 双色球概率实验室 - 测试规格

## 视图模块协调

| 场景 | 前置条件 | 执行动作 | 预期结果 |
|---|---|---|---|
| 页面初始化恢复本地状态与旧数据迁移 | IndexedDB 或旧版 localStorage 中存在合法数据 | 创建页面视图模块并执行初始化 | 首次迁移后从 IndexedDB 读取开奖记录、预测快照和当前算法；迁移或损坏存储不阻塞页面且给出可见提示，旧 localStorage 数据不被删除。 |
| 导入新开奖后触发对照 | 存在数据截止期早于新记录的未对照预测快照 | 导入合法的新期开奖 | 保存新记录后执行一次对照；对应快照保留原始号码并出现命中结果。 |
| 首次自动全量同步后触发对照 | IndexedDB 没有开奖记录，存在待对照预测快照，官方数据含后续开奖 | 页面初始化 | 所有页成功后仅新增期号写入 IndexedDB，并为符合条件的快照创建首个后续开奖对照。 |
| 已有数据时启动补拉 | IndexedDB 已有开奖记录 | 页面初始化或页面重新可见 | 只请求官方第 1 页，写入其中的新期号并对照；不拉取历史全部页。 |
| 开奖日定时补拉与重试 | 页面开启，当前北京时间为开奖日 21:30，官方结果尚未发布 | 到点触发定时器 | 先请求官方第 1 页；若最新开奖日期未到当日，5 分钟后重试，最晚到 22:30；成功或超时后排定下一开奖日。 |
| 官方同步任意页失败不写入 | 已有本地数据，首次全量同步的第二页请求失败或返回异常 | 页面初始化自动全量同步 | 返回可读错误；本轮远程记录、已有数据和复盘状态均不变化。 |
| 切换算法恢复各自最近候选 | 至少已有时间衰减和另一种算法的已保存预测快照 | 从时间衰减切换到其他算法，再切回时间衰减 | 工作区恢复时间衰减最近快照的 5 组 / 15 注和证明过程；不重新生成、不写入、不改写任何快照。 |
| 刷新后恢复各算法最近候选 | 多种算法均有已保存预测快照 | 刷新页面或恢复合法备份后切换算法 | 每种预测型算法按 `recordedAt` 恢复其最新快照；随机性审计不显示预测批次。 |
| 预测型算法生成自身研究覆盖候选 | 已保存至少一条开奖记录 | 分别选择贝叶斯、时间衰减、组合依赖、评分集成和覆盖优化并生成 | 每种候选的 `effectiveAlgorithmId` 与所选算法一致；生成正好 5 个大组 / 15 注；未通过验证时标为研究候选而非回退均匀基准。 |
| 每组奖级覆盖结构正确 | 已生成任一预测型算法批次 | 检查每个大组 | 锚点票为 6 红 + 主蓝；蓝球覆盖票同 6 红且蓝球不同；红球覆盖票同主蓝、保留 5 红并替换 1 红；15 注整体不重复。 |
| 证明过程可追溯 | 已生成任一预测型算法批次 | 查看 5 个大组的证明过程 | 每组都有锚点计算、备用蓝排名 / 权重、红球替换理由、候选身份和回测指标摘要。 |
| 冻结滚动回测不使用未来数据 | 至少 340 条开奖记录 | 运行回测 | 每个评估期只使用该期前最近 160 期；评估期最多 180 个，且模型候选按固定种子可复现。 |
| 回测指标与候选身份 | 已完成至少 120 个评估期 | 运行回测并生成候选 | 显示平均红球命中、蓝球命中率、复合分差、95% 下界和逐期胜率；只有下界大于 0 的模型标为回测通过。 |
| 导出完整备份 | IndexedDB 中存在开奖记录和快照 | 请求导出备份 | 生成包含版本、导出时间、开奖记录、快照、对照和当前算法的合法 JSON，不改变本地数据。 |
| 拒绝损坏备份 | IndexedDB 中已有数据 | 导入缺少必需字段、号码非法或关联失效的 JSON | 返回可读错误，现有 IndexedDB 记录和页面状态不变。 |
| 恢复合法备份并重新对照 | 存在符合版本与完整性规则的 JSON 备份 | 确认恢复 | 全量替换 IndexedDB 数据，恢复算法选择，并重新对照符合条件的未对照快照。 |

## 开奖数据单元

| 场景 | 前置条件 | 执行动作 | 预期结果 |
|---|---|---|---|
| 保存合法单期数据 | 输入完整合法记录且 IndexedDB 可用 | 调用保存单期方法 | 记录按日期、期号排序持久化到 IndexedDB，并更新最新期信息。 |
| 拒绝重复期号 | 本地已有相同期号 | 再次导入该期数据 | 返回重复错误，不修改已有数据。 |
| 拒绝非法红球 | 红球缺失、超范围或有重复 | 保存或导入记录 | 返回可读校验错误，不保存该条记录。 |
| 导入 CSV 时保留有效条目 | CSV 同时包含合法、非法和重复行 | 调用 CSV 导入方法 | 合法且未重复条目被保存；被拒绝行按行返回原因。 |
| 首次分页同步官方全部历史 | 官方接口返回多个 `pageNum` 页面，IndexedDB 为空 | 页面初始化 | 从第 1 页顺序请求至 `pageNum`，每页显示页码和已收集数量；所有页面成功后才写入新增期号。 |
| 自动补拉仅取最新页 | IndexedDB 已有开奖记录 | 调用最新开奖同步方法 | 仅请求官方第 1 页，不请求第 2 页及以后页面；仅保存新增期号。 |
| 官方同步跳过重复和非法记录 | IndexedDB 已有部分期号，官方响应同时有重复与非法号码 | 调用官方同步方法 | 已存在期号不覆盖；非法远程记录计入跳过数量；其他合法新记录一次保存。 |

## 候选计算单元

| 场景 | 前置条件 | 执行动作 | 预期结果 |
|---|---|---|---|
| 基准模型生成五组合法覆盖组合 | 至少已有一条合法开奖记录 | 用均匀组合基准生成候选 | 生成 5 个大组 / 15 注，红球排序、范围合法、覆盖结构正确且整注不重复。 |
| 数据不足时研究候选仍可生成 | 历史期数少于 161 条 | 选择任一非基准预测模型并生成 | 批次使用所选算法自身计算并标为研究候选；回测区显示数据不足，不伪造验证结论。 |
| 审计算法不产生购票候选 | 选择随机性审计算法 | 请求算法结果 | 返回审计指标，不创建预测快照。 |
| 已存数据下生成的候选可追溯 | 已保存开奖记录 | 生成候选 | 结果含算法、数据截止期、参数版本、种子和生成时间。 |

## 复盘单元

| 场景 | 前置条件 | 执行动作 | 预期结果 |
|---|---|---|---|
| 计算单注命中结构与奖级 | 存在预测组合和开奖组合 | 调用对照方法 | 返回 0–6 个命中红球、蓝球命中布尔值、可读标签；仅在 `6+1 / 6+0 / 5+1` 时标注一等奖 / 二等奖 / 三等奖。 |
| 仅使用首个后续开奖 | 快照之后存在多条开奖记录 | 执行对照 | 只绑定按规则排序的第一条后续开奖记录，不重复绑定后续期。 |
| 显示理论与经验值的边界 | 存在至少一条快照 | 读取统计摘要 | 理论概率和样本命中统计分区展示，并含非承诺说明。 |

## 当前无法自动化的场景

| 场景 | 原因 | 替代证据 |
|---|---|---|
| 组件交互、浏览器 IndexedDB 迁移、开发代理与生产反向代理、页面开启时的定时器、下载 / 上传交互 | 当前项目没有已有单元测试或浏览器自动化设施，本轮不新增测试框架。 | TypeScript 检查、生产构建、内存 API 与北京时间调度验证，以及本地浏览器手工等待、同步、导入、导出、恢复、刷新恢复和开奖对照。 |
